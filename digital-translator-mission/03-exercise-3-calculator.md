# Exercise 3: Calculator

## 1. Understanding the Task

The task is to create a simple calculator that accepts two numbers and performs four mathematical operations:

- Addition
- Subtraction
- Multiplication
- Division

The calculator must also handle division by zero.

## 2. Input

The two numbers provided are:

- First number: 20
- Second number: 5

## 3. Processing

The calculator performs the following operations:

| Operation | Calculation | Result |
|---|---|---:|
| Addition | 20 + 5 | 25 |
| Subtraction | 20 - 5 | 15 |
| Multiplication | 20 × 5 | 100 |
| Division | 20 ÷ 5 | 4 |

## 4. Error Handling

Division by zero is not allowed because a number cannot be divided by zero.

If the second number is zero, the calculator should display:

**Error: Division by zero is not allowed.**

## 5. INPUT → PROCESS → OUTPUT

**INPUT:** Receive two numbers from the user.

**PROCESS:** Perform the selected mathematical operation using the two numbers.

**OUTPUT:** Display the calculation result or an error message if the operation is invalid.

## 6. Expected Result

For the inputs 20 and 5, the calculator should display:

- Addition: 25
- Subtraction: 15
- Multiplication: 100
- Division: 4

## 7. Lesson Learned

A computer receives data as input, follows instructions to process it, and produces an output. A good program should also handle errors such as division by zero.
