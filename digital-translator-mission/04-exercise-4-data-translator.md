# Exercise 4: Data Translator

## 1. Customer Information

The customer information provided is:

- Name: Victor
- Age: 30
- Account Balance: 150000.50
- Active: Yes

## 2. Identifying the Data Types

| Information | Value | Data Type |
|---|---|---|
| Name | Victor | String |
| Age | 30 | Integer |
| Account Balance | 150000.50 | Float |
| Active | True | Boolean |

**Explanation:**

- **String:** Text or characters, such as a person's name.
- **Integer:** A whole number without a decimal point.
- **Float:** A number that contains a decimal point.
- **Boolean:** A value that represents either True or False.

## 3. What Is Data?

Data is information that a computer can store, process, and communicate.

## 4. How Computers Represent Information

Information passes through these stages:

1. **Real-world information:** Information about people or things, such as Victor's name and account balance.
2. **Data representation:** The information is organised into suitable data types, such as strings, integers, floats and booleans.
3. **Digital representation:** The information is converted into a form that a computer can work with.
4. **Binary representation:** Computers represent digital information using bits, which have values of 0 or 1.
5. **Storage:** The computer stores the represented information so it can be accessed and used later.

## 5. Understanding Bits and Bytes

- A **bit** is the smallest unit of digital information. It can be either 0 or 1.
- **8 bits** make up one byte.
- Computers use combinations of bits to represent information.

For example, in ASCII encoding, the capital letter A is represented as:

`01000001`

## 6. Why Data Accuracy Matters

Accurate data is important because computers use the information they receive to produce results.

For example, if Victor's actual account balance is ₦150,000.50 but the computer records it as ₦15,000.50, the displayed balance will be incorrect.

This could lead to wrong calculations, financial mistakes and poor decisions.

## 7. Lesson Learned

Computers need information to be represented in a form they can process and store. Accurate data helps computers produce correct and reliable results.
