## About This Mission

This repository was created for the Squad mission workspace as part of the Learn2Earn AI Engineering Programme.

The purpose of this mission is to understand how computers work with data and instructions to perform tasks.

It focuses on logical thinking, problem-solving, algorithms, data representation, input, processing and output.

## Learning Objectives

Through this mission, I aim to understand:

- How to break problems into smaller steps.
- How to write clear algorithms.
- How computers receive and process data.
- How to identify basic data types.
- How computers represent information digitally.
- Why accuracy and error handling matter.

## Key Concept

**INPUT → PROCESS → OUTPUT**

A computer receives data, follows instructions to process it, and produces a result.
